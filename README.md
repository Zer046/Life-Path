# Life Path

A static Digital Human Twin prototype for exploring everyday decisions.

Open `index.html` in a browser. The page includes its styles, scripts, and illustration images, and does not require a build step.

The Amelia profile and job outcomes are illustrative demo content. Simulations shown in this prototype are predefined scenarios.

## GitHub Pages

In the repository settings, open Pages and select Deploy from a branch. Select the main branch and the root folder, then save.
